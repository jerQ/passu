# passu - ESP32 diceware generator

> [!CAUTION]
> This is a proof of concept. It works and is tested, but it has not had an
> independent security review. There are no guarantees of security or of the
> quality of the generated data. All code is generated by Claude Code.

*Passu* is Finnish slang for "password".

passu turns a small, cheap ESP32 board into a passphrase generator. Plug it
into a computer, press a button, and you get a long, random, easy-to-type
passphrase like this (not a real one):

```text
apple3-sturdy7-orbit0-canopy5-mellow2-zigzag9-fossil4-tundra1
```

Each part is a word from the [EFF wordlist](https://www.eff.org/dice) and a
digit. The randomness comes from the chip's own hardware random number
generator, not from your computer.

This page shows how to put passu on a board and use it, no programming
needed. To build it yourself or change its settings, see
[BUILDING.md](BUILDING.md).

## How strong is it?

The board makes 8 groups of word + digit, worth about **130 bits** of
randomness. That is far more than any attacker can guess.

You can use fewer groups if a site limits the length: take the **first** few
groups and leave the rest. Don't pick the groups you like best, because that
makes the result less random. The `passu` command does this for you: it
gives 5 groups unless you ask for a different number with `-w` (up to 32),
and can leave out the digits with `--no-digits`.

| Groups | With digits | Words only |
| --- | --- | --- |
| 4 | ~65 bits | ~52 bits |
| 5 | ~81 bits (`passu` default) | ~65 bits |
| 6 | ~97 bits | ~78 bits |
| 7 | ~114 bits | ~90 bits |
| 8 | ~130 bits (all of them) | ~103 bits |

## What you need

1. **A supported board.** Find yours in the table to know which firmware
   file to download. The chip name is printed on the board's metal cover or
   on the chip itself.

   | Board | How to recognise it | Firmware file | Status |
   | --- | --- | --- | --- |
   | ESP32 (classic) | Cover says ESP32-WROOM-32 or similar; a separate small USB chip (CP2102, CH340) next to the USB socket | `passu-<version>-esp32.bin` | Tested |
   | ESP32-C3 with native USB | Chip or cover says ESP32-C3; no separate USB chip (for example "Super Mini" boards) | `passu-<version>-esp32c3.bin` | Tested |
   | ESP32-C3 with a separate USB chip | Says ESP32-C3, with a CP2102 or CH340 chip next to the USB socket | None: the ready-made firmware doesn't talk through that chip | Build it yourself |

   The board needs at least 4 MB of flash memory, which almost all of these
   boards have.

   For boards without a ready-made firmware file,
   [BUILDING.md](BUILDING.md#supported-boards) shows how to build passu
   yourself.

2. **A USB data cable.** Some cables only charge and carry no data. If the
   computer doesn't notice the board, try another cable.
3. **Google Chrome or Microsoft Edge** on a computer, to install the
   firmware. Firefox and Safari can't talk to USB devices this way.

## Install passu on the board

You only need to do this once (and again for new versions).

### 1. Download the firmware

1. Open the [Releases page](https://github.com/jerQ/passu/releases).
2. Under the newest release, open **Assets** and download the `.bin` file
   for your board (see the table above).

Optional check, for Linux users: download `SHA256SUMS` from the same release
into the same folder and run `sha256sum -c --ignore-missing SHA256SUMS`. It
should say `OK`.

### 2. Flash it from the browser

1. Plug the board into the computer.
2. In Chrome or Edge, open Espressif's web flasher:
   <https://espressif.github.io/esptool-js/>
3. Set **Baudrate** to **115200**. Faster speeds fail on some boards and
   USB chips.
4. Click **Connect**. A window lists the USB devices: pick the board and
   click **Connect** again.
   - A classic ESP32 usually shows up as *CP2102* or *USB Serial* (CH340).
   - An ESP32-C3 with native USB shows up as *USB JTAG/serial debug unit*.
5. In the programming section, set **Flash Address** to `0x0` and choose
   the `.bin` file you downloaded.
6. Click **Program** and wait until it says it is finished (about a
   minute).
7. Press the board's **RST** (or **EN**) button, or unplug and replug it.
   passu is now running.

**It doesn't connect?** Hold down the **BOOT** button on the board, click
Connect, and let go of BOOT once the flashing starts. Check that the
baud rate is 115200. Also try another cable or USB port.

**Prefer the terminal?** With Python installed:

```bash
pip install esptool
esptool -b 115200 write-flash 0x0 passu-<version>-<chip>.bin
```

## Get a passphrase with the BOOT button

The board's **BOOT** button makes a new passphrase. It shows up on the
computer in a serial terminal, a window that shows text from the board.
This works on any computer with Chrome or Edge:

1. Open the [web flasher](https://espressif.github.io/esptool-js/) again.
   If you just flashed the board, click **Disconnect** first.
2. In the **Console** section, set the baud rate to **115200** and click
   **Start**. Pick the board in the window that opens.
3. Press **BOOT** on the board. A passphrase appears on its own line.
   Press again for a new one.
4. Copy the passphrase, then close the page.

The `passu` command below can also wait for BOOT presses:
`passu --button` on Linux, `passu -Button` on Windows.

## Get a passphrase with the passu command (Linux)

`passu` is a small program that asks the board for a passphrase and prints
only that, or copies it straight to the clipboard. No button press needed.

### One-time setup

Open a terminal and run these commands.

1. Install the serial port library for Python:

   ```bash
   sudo dnf install python3-pyserial     # Fedora
   sudo apt install python3-serial       # Debian, Ubuntu
   ```

2. Allow your user to use serial ports, then **log out and back in**:

   ```bash
   sudo usermod -aG dialout $USER
   ```

3. Download the `passu` command:

   ```bash
   mkdir -p ~/.local/bin
   curl -fLo ~/.local/bin/passu https://raw.githubusercontent.com/jerQ/passu/main/tools/passu.py
   chmod +x ~/.local/bin/passu
   ```

   If the terminal later says `passu: command not found`, log out and back
   in, or run it as `~/.local/bin/passu`.

### Use it

Plug in the board, close any open serial terminal (only one program can use
the board at a time), and run:

| Command | What it does |
| --- | --- |
| `passu` | Prints one passphrase of 5 words |
| `passu -w 8` | Uses 8 words instead of 5 (anything from 1 to 32) |
| `passu --no-digits` | Leaves out the digit after each word |
| `passu -s` | Uses spaces between the words instead of `-` |
| `passu --copy` | Copies the passphrase to the clipboard instead of showing it |
| `passu -n 3` | Prints three passphrases |
| `passu --button` | Waits for you to press BOOT for each passphrase |

Options can be combined: `passu -w 6 --no-digits -s --copy`. The table in
[How strong is it?](#how-strong-is-it) shows what each length is worth.

`--copy` needs `wl-copy` (Wayland) or `xclip` installed. If it says no
clipboard tool was found: `sudo dnf install wl-clipboard` (or
`sudo apt install wl-clipboard`).

The full list of options and messages is in [USAGE.md](USAGE.md).

## Get a passphrase with the passu command (Windows)

The Windows version of `passu` is a PowerShell script. It needs nothing
extra: Windows 10 and 11 already have PowerShell.

### One-time setup

1. Plug in the board. Windows usually installs the USB driver by itself.
   If the board doesn't appear under **Ports (COM & LPT)** in Device
   Manager, install the driver for its USB chip (CP210x from Silicon Labs,
   or CH340 from WCH).

2. Open **PowerShell** (not as administrator) and paste:

   ```powershell
   $dir = "$env:LOCALAPPDATA\passu"
   New-Item -ItemType Directory -Force $dir | Out-Null
   foreach ($f in 'passu.ps1', 'passu.cmd') {
       Invoke-WebRequest "https://raw.githubusercontent.com/jerQ/passu/main/tools/$f" -OutFile "$dir\$f"
   }
   $path = [Environment]::GetEnvironmentVariable('Path', 'User')
   if ($path -notlike "*$dir*") {
       [Environment]::SetEnvironmentVariable('Path', "$path;$dir", 'User')
   }
   ```

3. Close PowerShell and open it again, so it finds the new command.

`passu.cmd` starts `passu.ps1` for you, so you don't need to change
PowerShell's script execution policy. `passu` works in PowerShell and in
the Command Prompt.

### Use it

Plug in the board, close any open serial terminal (only one program can use
the board at a time), and run:

| Command | What it does |
| --- | --- |
| `passu` | Prints one passphrase of 5 words |
| `passu -w 8` | Uses 8 words instead of 5 (anything from 1 to 32) |
| `passu -NoDigits` | Leaves out the digit after each word |
| `passu -s` | Uses spaces between the words instead of `-` |
| `passu -Copy` | Copies the passphrase to the clipboard instead of showing it |
| `passu -n 3` | Prints three passphrases |
| `passu -Button` | Waits for you to press BOOT for each passphrase |
| `passu -Port COM5` | Uses this port, if passu can't pick the board by itself |

Options can be combined: `passu -w 6 -NoDigits -s -Copy`.

The messages are the same as on Linux; see [USAGE.md](USAGE.md).

## Good habits

- **Don't leave passphrases on screen.** Use `passu --copy` (`passu -Copy` on Windows), or clear the
  terminal or close the browser page afterwards.
- **The computer sees the passphrase.** It travels over USB to the computer.
  If you don't trust the computer, don't use it to generate passphrases.
- **Keep the board to yourself.** Someone who can reprogram the board could
  replace passu with firmware that makes passphrases they know.
- **Use each passphrase once.** Generate a new one for each account.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The web flasher doesn't list the board | Use another USB cable (it may be charge-only) or another USB port. On Linux, check that you are in the `dialout` group. On Windows, check that it appears in Device Manager under Ports (COM & LPT) |
| The web flasher can't connect, or stops with an error such as "Failed to start stub flasher" | Set the baud rate to 115200; hold BOOT while clicking Connect; use another cable or port; close other programs using the board |
| Nothing happens when I press BOOT | Make sure the console is started at 115200. Press RST/EN once and try again. Check that you flashed the right file for your board |
| `passu`: No ESP32 found | Plug the board in with a data cable. Wait a few seconds after plugging in |
| `passu`: the port is busy | Close the browser console or any other serial terminal |
| `passu`: No permission | Join the `dialout` group (setup step 2) and log out and back in |
| `passu`: No answer from the device | Press RST/EN on the board and try again. Check that you flashed the right file for your board |
| `entropy health failure` or `previous run crashed` | Unplug the board and plug it back in. If it keeps happening, stop using the board |

The board refuses to make a passphrase whenever its own self-checks fail.
No passphrase is better than a bad one.
